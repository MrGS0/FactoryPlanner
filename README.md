# Factory Planner

A production planner for the factory game Satisfactory™. Pick what you want to make and it lays out every machine, belt and resource you need. Then click any machine to change its recipe, split it across recipes, overclock it or add Somersloops.

**Open it:** https://mrgs0.github.io/FactoryPlanner/

## Using it

- Add the items you want under **Production** and anything you already have under **Inputs**.
- Tick the alternate recipes you have unlocked under **Options**.
- Each machine in the graph shows how many buildings to place and the clock speed they run at, for example "3 needed · 75 %".
- **Max from inputs** makes as much as your inputs allow.
- Ctrl+Z undoes and Ctrl+Y redoes.

## Sharing a plan

The plan lives in the page address, so **Copy link** gives a link that opens the same plan for anyone. **Copy plan code**, **Export JSON** and links from satisfactory-calculator.com work too.

## Offline

Everything is in the single `index.html`. Download it and open it from disk to use the planner without internet. When it is opened from disk, share plans with **Copy plan code** instead of **Copy link**.
